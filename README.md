# Ternary Hex

**Author: j-mosij**

Reusable pure-static SVG automata marks for any GitHub repository or GitHub Pages site.

![mini hex](docs/mini-hex.svg)

## Marks

| Mark | Use |
|------|-----|
| `docs/mini-hex.svg` | 80×80 badge |
| `docs/hex-3d.svg` | isometric 3D-style hex |
| `docs/banner.svg` | wide banner |
| `docs/ticker.svg` | compact ticker strip |
